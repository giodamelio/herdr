---
title: ブラウザクライアント
description: 使い捨てリンクで Herdr の TUI をブラウザに配信し、作成されたセッションを管理します。
---

Herdr はターミナル UI をブラウザに配信できます。サーバーはネットワーククライアント
向けに差分化したターミナル出力をすでに生成しているため、ブラウザ側はターミナル
エミュレータを動かすだけです。ペインもキーバインドもエージェントも同じものが使えます。

この機能は既定で無効で、有効にするまで無効のままです。

## ブラウザクライアントを有効にする

設定に `[web]` セクションを追加し、サーバーを再起動または再読み込みします。

```toml
[web]
enabled = true
```

続いて再読み込みします。

```bash
herdr server reload-config
```

## セッションを開く

リンクを発行します。

```bash
herdr web connect
```

このリンクは一度だけ有効で、5 分で失効します。開くとセッション Cookie が設定され
クライアントへリダイレクトされるため、トークンがページに渡ることも、アドレスバーに
残ることもありません。

Cookie は再読み込みやタブを閉じても残ります。ブラウザを終了したとき、セッションを
失効させたとき、Herdr サーバーが停止したときに消えます。そうなったら
`herdr web connect` を再実行して新しいリンクを取得してください。

呼び出すたびに新しいリンクが発行され、複数のブラウザが同時にセッションを保持できます。
Herdr はそれぞれを独立したクライアントとして扱うので、ノート PC とスマートフォンで
同じセッションを一緒に見られます。

## 別のマシンから接続する

既定ではループバックのカーネル割り当てポートにバインドするため、Herdr を実行している
マシンからしか到達できません。これは意図的な設定です。リスナーは平文 HTTP を話し、
TLS の終端は別のものに任せます。

`tailscale serve` を使うと、証明書付きの実際のホスト名の背後に置けます。

```bash
tailscale serve --bg 7777
```

ポートを固定し、到達に使う origin を Herdr に伝えると、表示されるリンクが実際に
開けるものになります。

```toml
[web]
enabled = true
bind = "127.0.0.1:7777"
public_url = "https://box.tail1234.ts.net"
```

SSH トンネルでも構いません。

```bash
ssh -L 7777:127.0.0.1:7777 you@your-host
```

1 回のリンクだけ origin を上書きすることもできます。

```bash
herdr web connect --url https://box.tail1234.ts.net
```

HTTPS は任意というより実質的に必須です。セッション Cookie に `Secure` が付くのは
https origin のときだけで、ブラウザはセキュアコンテキスト以外でページからの
クリップボード書き込みを拒否します。そのため平文 HTTP ではペインからのコピーが
機能しなくなります。

## セッションを管理する

現在有効な Cookie を保持しているブラウザセッションを一覧します。

```bash
herdr web sessions
```

```text
SESSION        CONNECTIONS  LAST SEEN
9f2c41ab77de   1            3s ago
```

`CONNECTIONS` は今まさに接続しているブラウザの数です。接続数が 0 のセッションも
Cookie は保持しており、再接続できます。

ハンドルを指定して失効させます。Cookie が無効になり、接続中のものは即座に切断されます。

```bash
herdr web disconnect 9f2c41ab77de
```

## 設定項目

```toml
[web]
# TUI をブラウザに配信するかどうか。既定値: false
enabled = false
# リスナーのバインド先。既定値: ループバックのカーネル割り当てポート
bind = "127.0.0.1:0"
# リスナーの前面に立つ origin。空の場合は http://<bind> を使います
public_url = ""
# 最初の connect ではなくサーバー起動時にバインドします。既定値: false
autostart = false
# 接続リンクの有効期間。既定値: 300
invite_ttl_secs = 300
```

`enabled` と `public_url` は `herdr server reload-config` で反映されます。
`enabled` を false に戻して再読み込みすると、リスナーは停止し、すべてのブラウザ
セッションも一緒に終了します。`bind` の変更にはサーバーの再起動が必要です。
リスナーは機能が有効なあいだバインドされたままだからです。

## 既知の制限

Kitty グラフィックスは描画されません。ブラウザはセルのピクセルサイズを報告しないため、
サーバーは画像バイトをストリームに含めません。エージェントへの画像貼り付けは引き続き
動作し、失われるのはインラインプレビューだけです。

ブラウザは一部のキー組み合わせを自身のために予約しています。`ctrl+w`、`ctrl+t`、
`ctrl+n` はブラウザが処理し、ペインには届きません。Herdr 自身のキーバインドは
プレフィックス方式なので影響を受けません。

セッションはライブハンドオフを越えて維持されません。`herdr server live-handoff` は
トークンを保持しているプロセスを置き換えるため、接続中のブラウザにはセッション終了が
表示され、新しいリンクを発行することになります。
